# Shorts AI Studio — первая версия

Локальное Windows-приложение для подготовки вертикальных клипов из видео.

## Что уже реализовано
- Графический интерфейс на русском языке.
- Загрузка MP4/MKV/AVI/MOV/WebM.
- Выбор количества клипов (1–50) и длительности (15/30/45/60 сек.).
- Категории сцен с независимыми галочками; если не выбрано ничего — включается автоматический режим.
- Опциональное распознавание речи через faster-whisper.
- Создание MP4 в вертикальном формате 1080×1920.
- Папка результатов `Shorts_AI_Studio_Clips` рядом с исходным видео.

## Важно о текущем MVP
Это первая рабочая основа, а не полноценный семантический ИИ-монтажёр. Сейчас приложение распознаёт речь (если установлен faster-whisper) и использует простую эвристику для ранжирования фрагментов. При отсутствии распознавания речи оно равномерно выбирает отрезки по ролику. Выбранные категории пока сохраняются в настройках интерфейса, но тонкая классификация по каждой категории требует следующего этапа интеграции мультимодальной модели. Субтитры и онлайн-поиск трендов также подготовлены как следующие модули, но ещё не реализованы в этой сборке.

## Установка в Windows 10/11

1. Установи Python 3.11 (отметь `Add Python to PATH`).
2. Установи FFmpeg и добавь папку `bin` в системный PATH. Проверь в PowerShell:
   ```powershell
   ffmpeg -version
   ffprobe -version
   ```
3. Распакуй архив в удобную папку.
4. Открой PowerShell в папке проекта и выполни:
   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   python main.py
   ```

При первом запуске faster-whisper может скачать модель распознавания речи. Модель `base` работает локально после загрузки; скорость зависит от процессора и объёма RAM.

## Сборка EXE

После установки зависимостей:
```powershell
pip install pyinstaller
pyinstaller --noconfirm --windowed --name "Shorts AI Studio" main.py
```
EXE появится в `dist\Shorts AI Studio\Shorts AI Studio.exe`. FFmpeg должен быть доступен в PATH и на компьютере пользователя.
