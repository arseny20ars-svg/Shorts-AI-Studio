# Shorts AI Studio — проект с автоматической Windows-сборкой

В этой версии добавлена автоматическая сборка установщика Windows 10/11 через GitHub Actions. Локально устанавливать Python, PowerShell, FFmpeg или PyInstaller на своём компьютере не требуется.

## Как получить установщик без локальной установки Python

1. Создай пустой репозиторий на GitHub (можно приватный).
2. Загрузи в него всё содержимое этой папки проекта через браузер GitHub (кнопка **Add file → Upload files**), затем нажми **Commit changes**.
3. Открой вкладку **Actions** репозитория. Если GitHub попросит разрешить Actions, разреши.
4. Запусти workflow **Build Windows installer** кнопкой **Run workflow** (либо дождись автоматического запуска после загрузки файлов).
5. Когда сборка завершится успешно, открой её страницу в Actions, найди **Artifacts** и скачай `Shorts-AI-Studio-Windows-Setup`.
6. Распакуй скачанный артефакт и запусти `Shorts_AI_Studio_Setup.exe`.

GitHub выполняет сборку на Windows-сервере. На твоём ПК Python и PowerShell устанавливать не нужно. GitHub-аккаунт нужен для запуска сборки.

## Состояние функциональности

Это ранний MVP. Уже есть интерфейс, выбор исходного видео, число/длительность клипов, категории с независимыми галочками и экспорт вертикальных MP4. Распознавание речи через faster-whisper опционально и при первом использовании может загрузить модель.

Пока НЕ реализованы полноценное понимание видеосцен по всем категориям, автоматические субтитры, встроенный видеоплеер/предпросмотр и реальный сбор трендов YouTube/TikTok. Нынешний подбор сцен — базовая эвристика по распознанной речи или равномерный резервный подбор. Не следует считать его готовым интеллектуальным монтажёром.

## Важно

Сборка включает FFmpeg. Модель распознавания речи скачивается при первом запуске и требует интернет. Используй только видео, на обработку и публикацию которых у тебя есть необходимые права.
